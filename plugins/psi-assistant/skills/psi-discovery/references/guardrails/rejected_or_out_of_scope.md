# Rejected or out-of-scope guardrails

- Mandatory legacy/recency flagging is not required (accepted residual risk).
- Unit conversion/transformation is excluded (report-as-source only).
- RiskAgent risks excluded from active monitoring: `societal-impact`, `static-knowledge`, `outdated-confidence`.
- User override of guardrails is not permitted.
- Dual-use hazardous-synthesis prohibition is not treated as a primary control because the public PSI corpus is export-controlled; misuse attempts are handled via adversarial/jailbreak guardrails.
