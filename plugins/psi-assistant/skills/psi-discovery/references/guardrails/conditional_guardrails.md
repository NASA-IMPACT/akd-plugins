# Conditional / context-dependent guardrails (SME-validated)

- Interpretation: permitted only with evidence + per-interpretive-statement verification caveat.
- Estimation: permitted only when explicitly requested by the user, and explicitly labeled as non-PSI estimate.
- Alternate-investigation recommendation: permitted only when clearly labeled and offered for user review.
- Procedural description: permitted only when it stays descriptive (as documented) and does not cross into medical/clinical/biosafety advice.
- Cross-domain comparison: permitted only with comparability caveat.
- Dataset selection/validation: agent may recommend (labeled); user makes final decision.
- Refusal messaging style: depends on behavioral heuristic (first/low-confidence vs repeated/high-confidence adversarial signals).
