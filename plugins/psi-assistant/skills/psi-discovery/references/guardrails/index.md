# Guardrails manifest (draft)

This directory defines safety boundaries, misuse protections, and assurance rules for the PSI scientific knowledge & data assistant.

- `safety_scope_summary.md` — safety scope and key risk drivers.
- `approved_guardrails.md` — SME-validated guardrails (by dimension).
- `conditional_guardrails.md` — context-dependent guardrails (SME-validated).
- `rejected_or_out_of_scope.md` — rejected/out-of-scope guardrails and accepted residual risks.
- `escalation_and_review_triggers.md` — escalation rules and thresholds.
- `never_do_rules.md` — non-negotiable prohibitions.
- `provider_configuration.md` — GraniteGuardianTool + RiskAgent configuration (SME selections).
- `enforcement_matrix.md` — approved signals → enforcement actions matrix.
- `open_questions_and_residual_risks.md` — open items and residual risks.
