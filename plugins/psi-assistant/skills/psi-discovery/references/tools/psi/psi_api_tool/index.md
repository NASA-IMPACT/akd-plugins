# psi_api_tool (draft)

## Purpose
Single PSI runtime tool for API-backed investigation operations.

## In scope
- Investigation discovery
- Investigation file search
- File retrieval
- Dataset navigation (folder reconstruction from `category + subcategory + subdirectory`)
- DataCite DOI/publication metadata lookup

## Out of scope
- Extraction, summarization, comparison
- Research gap / related-work discovery (v2)
